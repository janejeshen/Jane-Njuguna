# Audit and Recommendations

## Portfolio Audit

Current score before improvements: 6.5/10

The portfolio had solid technical content and strong project potential, but it was not positioned sharply enough for recruiters. Earlier copy leaned too general in places, some project descriptions sounded explanatory rather than achievement-driven, and the portfolio did not fully communicate business impact, rankings, metrics, or role fit within the first screen.

Strengths:

- Strong project foundation across BI, healthcare analytics, geospatial AI, NLP, and machine learning.
- Clear visual direction after dark-theme redesign.
- Strong differentiators: 2nd Place - Top Female, Macro F1 0.8663, 7th out of 99, 110,000+ records analyzed.
- Good technical breadth across Python, SQL, Power BI, PostgreSQL, ML, and NLP.

Weaknesses limiting interviews:

- Not enough proof of business impact in the first 10 seconds.
- Experience entries need dates, role titles, and quantified outcomes.
- Some project GitHub links need stronger README files, screenshots, architecture, setup instructions, and results sections.
- Portfolio needs stronger separation between BI/business analytics projects and AI/ML projects.
- Missing a dedicated case-study page for the Sentinel-2 project.
- Need one master CV instead of multiple role-specific CVs with inconsistent positioning.
- Profile should avoid student framing and lead with professional outcomes.

Portfolio score after improvements: 8.7/10

To reach 9.5/10:

- Add live case-study pages for the top 3 projects.
- Add project screenshots, model diagrams, metrics tables, and business recommendations.
- Add exact dates and measurable outcomes for Kiondo Market and Kurasa Africa.
- Add a downloadable master CV matching the portfolio positioning.
- Add testimonials, references, or short credibility quotes if available.

## UI/UX Recommendations

- Keep the dark glassmorphism direction but reduce visual clutter around the hero on small screens.
- Make the hero CTA hierarchy clear: View Projects first, Download CV second, GitHub and LinkedIn third.
- Add a sticky desktop nav and a working mobile menu.
- Add dedicated case-study pages instead of only project cards.
- Use consistent project image ratios and avoid generic stock imagery where actual dashboards/screenshots exist.
- Add microcopy that explains outcomes, not just tools.
- Add subtle animations: fade-up on section entry, card hover glow, smooth number counters, and project image reveal.
- Keep animations under 250ms to preserve premium feel.

## Mobile UI Recommendations

- Lead with badge, headline, one-line summary, CTA buttons, then photo.
- Make project cards single column with image, title, metrics, tags, and one clear action.
- Put GitHub, LinkedIn, Download CV, and Contact in a bottom action row or compact button group.
- Reduce hero headline size on small screens to avoid awkward wraps.
- Move stats below the hero and above projects on mobile.
- Ensure tap targets are at least 44px high.
- Avoid horizontal scrolling from wide grids or long tags.
- Add a mobile menu overlay with section links.

## Recruiter Recommendations

- Lead every platform with the same positioning: Data Analyst | BI Analyst | AI Engineer | Data Scientist.
- Make Sentinel-2 the hero project because it has ranking, technical depth, and measurable performance.
- Keep Sales & Inventory high for BI/Data Analyst roles.
- Keep Multilingual Health Assistant high for AI Engineer/NLP roles.
- Use exact metrics wherever possible: records analyzed, dashboards built, reporting time saved, model score, ranking, number of products, number of stakeholders.
- Replace phrases like "student", "aspiring", or "learning" with "building", "developed", "analyzed", "delivered", and "ranked".
- Create pinned GitHub repos for the top 5 projects in the same order as the portfolio.
- Each pinned repo should include problem, data, approach, architecture, results, screenshots, how to run, and business impact.
- Apply with tailored CV ordering instead of creating entirely separate identities.
